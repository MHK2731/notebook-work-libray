# Notebook Work Library

This repository contains the files which are currently used in one our website named "Notebook Work Library".
If you want to see the website live then go to:
            dpsnwl.rf.gd

## Local login server

A local backend login server has been added to the project.

### Start the server

1. Open a terminal in the repository root.
2. Run `npm install`.
3. Run `npm start`.
4. Open `http://localhost:3000` in your browser.
